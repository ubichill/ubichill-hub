world://build

ワールドは YAML、
機能は mod。

どちらも URL で配れる。権限は、使う人が握る。

  • ゼロトラストの Worker サンドボックス

    mod は Web Worker に隔離して実行。Host との境界は postMessage の一点だけ。

  • 権限は書かなくていい

    使った API からビルド時に静的解析で自動導出。初回使用時にだけ確認する。

  • 宣言的な状態同期

    Ubi.state.sync() 1 つで、全員共有・個人ごと・揮発を切り替え。

  • 完全 CSR + Go

    UI は Vite の CSR。インスタンス通信は独立した Go の WebSocket サーバー。

world://federation

どのサーバーの人とも、
同じ部屋に。

Ubichill は中央のサーバーを置きません。部屋のことは部屋のサーバーが、人のことはその人のホームのサーバーが決めます。ActivityPub（AS2）の形で、署名は Ed25519 + RFC 9421。

world://self-host

自分の場所は、自分で建てる。

global.domain を決めるだけで、Ingress も CORS も認証の URL も導出されます。DB は同梱の PostgreSQL がパスワードまで自動生成。

terminal · helm
zsh
$ helm repo add ubichill https://ubichill.github.io/ubichill
$ helm install ubichill ubichill/ubichill \
    -n ubichill --create-namespace \
    --set global.domain=<your-domain>
# => https://<your-domain> でワールドが開く

  2. 02 installHelm で入れる

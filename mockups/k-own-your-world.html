mod

mod はコードで書く。

TypeScript で書いて、Worker のサンドボックスで動く。

いいねボタン

const like = Ubi.state.define({
  count: Ubi.state.sync(0),
});

export default function LikeButton() {
  return (
    <button onClick={() => like.local.count++}>
      いいね {like.local.count}
    </button>
  );
}

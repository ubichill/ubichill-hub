WHY UBICHILL

軽くて、ゆるくて、どこにも縛られない。

顔も声も出さず、カーソルだけで「そこにいる」。それを特定の会社のサーバーではなく、Web の上に。

カーソルだけのゆるい繋がり

顔出しも声出しもなし。お互いの動線だけが伝わる、ちょうどいい存在感。

URL をひらくだけ

インストール不要。低スペックな PC やスマホからでも、ブラウザ 1 つで 1 秒で。

mod でなんでも足せる

ペン・動画・付箋。機能は URL から読み込む mod。ゼロトラストの Worker サンドボックスで安全に動く。

中央を持たない

サーバー同士が連合。どのサーバーの人ともフレンドになり、相手の部屋に入れる。

FEDERATION

部屋のことは部屋のサーバー、
人のことはその人のサーバー。

権威を分けるから、中央がいらない。形は ActivityPub（AS2）に合わせ、やりとりはすべて署名つき。

部屋の住所
chill-room部屋 ID @ yokan.example部屋のサーバー
  • 人のことは、ホームのサーバーフレンド申請・招待・プロフィールは、相手の inbox へ知らせる（非同期・送り直しあり）。
  • 部屋のことは、部屋のサーバー在室・公開範囲・入れるかどうかは、部屋のサーバーだけが知っていて、その場で答える。
  • 署名で確かめるEd25519 + RFC 9421。署名は宛先に縛られ、別のサーバーへは転用できない。

FOR DEVELOPERS

mod も、ワールドも、URL で配れる。

完全 CSR（Vite）と Go の WebSocket インスタンスサーバー。拡張は Worker の中で動く mod として、どのサーバーからでも読み込める。

mod

@ubichill/sdk だけに依存する Web Worker。状態は Ubi.state.sync で宣言するだけで同期。

World as Code

Kubernetes の CRD と同じ形の YAML。GitHub に置いても、ほかのサーバーに置いても開ける。

# 自分のサーバーを建てる
helm repo add ubichill https://ubichill.github.io/ubichill
helm install ubichill ubichill/ubichill \
  -n ubichill --create-namespace \
  --set global.domain=<your-domain>

# → https://<your-domain>/ap/actor が公開され、
#   ほかのサーバーと連合できるようになる
SELF-HOST

あなたのサーバーも、
網のひとつに。

Helm チャート 1 つで建てて、ドメインを決めるだけ。ほかのサーバーとは最初からつながります。

  1. 1
    Helm でインストールPostgreSQL 同梱、パスワードは自動生成
  2. 2
    ドメインを決めるIngress / CORS / 認証 URL は global.domain から導出
  3. 3
    連合に参加追加の設定なし。鍵は種から導出し、秘密鍵は保存しない

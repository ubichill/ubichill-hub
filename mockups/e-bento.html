For developers

mod とワールドは、コードで書く。

mod は Worker で隔離され、@ubichill/sdk だけに依存する。ワールドは YAML で宣言する。

mods/like/src/button.worker.tsxイメージ
const likes = Ubi.state.sync(0);

Ubi.ui.render(() => (
  <button onClick={() => likes.set(likes.get() + 1)}>
    いいね {likes.get()}
  </button>
));

宣言的な状態同期

Ubi.state.sync ひとつで、全員に共有・永続化。DOM には触らず、UI は VNode で描く。

Zero trust

権限は、使うときに聞く

危険度ティアごとに、初回使用時だけ確認。決めたことは覚えておく。

safe描画・状態同期確認なし
sensitive外部への fetchドメインごと
dangerous強い権限厳格に確認
Static analysis

ビルド時に Worker のコードを静的解析して、必要な権限を自動で導き出す。

Architecture

軽さのための分離

UI は完全 CSR。部屋の同期は独立した Go のサーバーが受け持つ。

Browser (Vite CSR)
WebSocket

Federation & self-host

自分のサーバーで、みんなとつながる。

部屋のことは部屋のサーバー、人のことはその人のホームのサーバーが決める。中央のサーバーは置かない。

ActivityPub-shaped

部屋には住所がある

どのサーバーの部屋にも、/instance/:住所 で入れる。フレンド申請や招待は AS2 の activity でやりとりし、Ed25519 + RFC 9421 で署名する。

chill-room@yokan.example
Self-host with Helm

Helm チャート 1 つで建つ

DB のパスワードは自動生成。メール認証を使わない設定もできる。

# チャートを追加して
helm repo add ubichill \
  https://ubichill.github.io/ubichill
# ドメインを決めてインストール
helm install ubichill ubichill/ubichill \
  -n ubichill --create-namespace \
  --set global.domain=<your-domain>

// for builders

ワールドは YAML、
機能は mod。

ワールドは URL で識別される YAML。機能は URL から読み込む mod。置いた場所が、そのまま配布先になる。

safe描画や状態同期など。確認なしで動く
sensitive外部への fetch など。ドメインごとに初回だけ確認
dangerousより強い権限。厳格な確認か拒否
  • 権限は宣言不要。ビルド時の静的解析で使っている API から自動導出
  • mod は Worker で隔離。信頼境界は Worker と Host の postMessage 1 点だけ
  • 外部依存ゼロの @ubichill/sdk。Ubi.state.sync で宣言的に同期
# worlds/chill-room.yaml
apiVersion: ubichill.com/v1alpha1
kind: World
metadata:
  name: chill-room
  version: "1.0.0"
spec:
  displayName: チルな作業部屋
  capacity: { max: 20, default: 10 }
  dependencies:
    - name: pen
    - name: video-player
  initialEntities:
    - id: pentray
      components:
        - type: pen:tray
// mods/like/src/button.worker.tsx（イメージ）
const likes = Ubi.state.sync(0);

Ubi.ui.render(() => (
  <button onClick={() => likes.set(likes.get() + 1)}>
    いいね {likes.get()}
  </button>
));

自分のサーバーを建てる

Helm チャートを 1 つ入れるだけ。global.domain から Ingress・CORS・認証 URL が導出され、PostgreSQL もパスワード自動生成で同梱される。

  • 完全 CSR（Vite）＋ Go の WebSocket インスタンスサーバー
  • Ed25519 ＋ RFC 9421 署名でサーバー間を確かめる
zsh
$ helm repo add ubichill https://ubichill.github.io/ubichill
$ helm install ubichill ubichill/ubichill \
    -n ubichill --create-namespace \
    --set global.domain=<your-domain>
✓ ubichill is running at https://<your-domain>

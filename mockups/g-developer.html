ワールドはコードで、
機能は URL で。

Ubichill は、みんなのカーソルが集まって、描いたり、観たり、いっしょに過ごす Web スペース。ワールドは YAML で書けて、機能は URL から読み込む mod で足せる。自分のサーバーも Helm チャート 1 つ。

アプリを開く ドキュメントを読む

01 / why

軽くて、安全で、
中央を持たない。

顔も声も出さずに「そこにいる」を共有するための、最小の仕組みだけを持つ。残りはすべて mod と URL に任せる。

01presence

カーソルだけのゆるい繋がり

顔出しも声出しもなし。お互いの動線だけが伝わる、ちょうどいい存在感。

avatar: cursor.cur
02zero-install

URL をひらくだけ

インストール不要。低スペックな PC やスマホからでも、ブラウザ 1 つで 1 秒で。

ubichill.com/@you/room
03mods

mod でなんでも足せる

ペン・動画・付箋。機能は URL から読み込む mod。ゼロトラストの Worker サンドボックスで動く。

Ubi.ui.render()
04federation

中央を持たない

サーバー同士が連合。どのサーバーの人ともフレンドになり、相手の部屋に入れる。

room@hub.example.com

04 / architecture

UI はブラウザに閉じ、
同期は Go が受け持つ。

完全 CSR のホストが mod を Worker に隔離して動かし、インスタンスの同期は独立した Go の WebSocket サーバーが行う。信頼境界は Worker → Host の postMessage の一点だけ。

browservite · csr

Host

UI・セッション・ルーティング・mod レジストリ

penWorker
videoWorker
your-modWorker
/realtime
WebSocket
services/instancego

Instance

部屋ごとの同期・presence・エンティティ

packages/backendapi

SNS API

アカウント・フレンド・ワールド（PostgreSQL）

AS2
RFC 9421
federationv1

ほかのサーバー

フレンド申請・招待は inbox へ、入室は部屋のサーバーへ署名付き RPC。

05 / mod sdk

権限は宣言しない。
使った API から導く。

mod は @ubichill/sdk だけに依存する。ビルド時に Worker のコードを静的解析して capability を自動生成し、読み込み時にユーザーがまとめて承認する。

Ubi.*
// 状態（宣言的に同期）Ubi.state.sync(0)                        // 全員共有 + 永続化Ubi.state.sync('', { perUser: true })   // ユーザーごとUbi.state.sync(pos, { ephemeral: true }) // 揮発 broadcast// UI・メディア・キャンバスUbi.ui.render(() => <Panel />)Ubi.media.load(url, 'main')Ubi.canvas.commitStroke('canvas', stroke)// 型付きイベントconst Ev = Ubi.event.define<{ 'like:add': { n: number } }>()Ev.emit('like:add', { n: 1 }, { ref: 'screen' })
safe自動で許可

ワールド内で完結し、外へは何も出ない。

ui:renderui:toastscene:readevent:emitasset:read
sensitive既定で許可

ワールドの状態を書き換える。設定で要承認にできる。

scene:updatecanvas:drawmedia:controlevent:broadcast
dangerous明示承認

外部通信。fetch は接続先ドメインごとに「今回だけ / 次回も / 拒否」。

net:fetchidentity:token
承認が済むまで Worker は実行されない。拒否された権限は実行時ゲートが個別に止め、必ずコンソールとトーストに出る。

06 / world as code

YAML が唯一の真実。
エディタでも書ける。

Kubernetes の CRD と同じ形（apiVersion / kind / metadata / spec）。ワールドは URL で識別され、GitHub にも、ほかのサーバーにも置ける。ワールド自体はステートレスで、インスタンスが生きている間だけ状態を持つ。

07 / federation & self-host

建てて、つなぐ。

部屋のことは部屋のサーバーが、人のことはその人のホームのサーバーが決める。中央のサーバーは置かない。

どのサーバーの部屋にも入れる

ActivityPub（AS2）の形で、相手は ubichill のサーバーだけ。部屋の住所はメールアドレスのように書ける。

chill-room@hub.example.com
鍵
Ed25519。actor ごとに種から導出し、秘密鍵は保存しない
署名
RFC 9421 + Content-Digest（RFC 9530）。宛先に縛られ転用できない
配送
フレンド申請・招待は inbox へ非同期、入室は部屋のサーバーへ同期 RPC
パブリックフレンド+フレンドのみ招待のみ

Helm チャート 1 つ

global.domain から Ingress・CORS・認証 URL まで導出。同梱の PostgreSQL はパスワードを自動生成する。

$ helm repo add ubichill https://ubichill.github.io/ubichill
$ helm install ubichill ubichill/ubichill -n ubichill --create-namespace \
--set global.domain=<your-domain> \
--set backend.secretEnv.BETTER_AUTH_SECRET=<random-secret>
k8s / k3sPostgreSQL 同梱GHCR イメージメール認証は任意インスタンスだけでも動く

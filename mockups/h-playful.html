作業通話ほど重くなく、メタバースほど大げさじゃない。ブラウザの中に、みんなのいる場所をつくる。

ワールドも機能も、自分で書ける。

mod は @ubichill/sdk だけに依存する小さな Worker。ワールドは YAML 1 枚。

mod をつくる

状態は Ubi.state で宣言するだけで、みんなに同期される。サーバーは書かない。

// like/button.worker.tsx（イメージ）
const likes = Ubi.state.sync(0);

Ubi.ui.render(() => (
  <button onClick={() =>
    likes.set(likes.get() + 1)}>
    いいね {likes.get()}
  </button>
));

ワールドを書く

World as Code。YAML が唯一の真実で、ワールドは URL で呼べる。

kind: World
metadata:
  name: chill-room
spec:
  displayName: チルな作業部屋
  capacity: { max: 20 }
  dependencies:
    - name: pen
    - name: video-player

こわくない権限

権限は使った API から自動で決まる。危ないものだけ、カメラ許可みたいに聞かれる。

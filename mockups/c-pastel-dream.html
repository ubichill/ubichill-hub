カーソルで、そこにいる。

Ubichill は、みんなのカーソルが集まって、描いたり、観たり、いっしょに過ごす Web スペース。URL を開くだけ。インストール不要、機能は誰でも URL で追加できる。

アプリを開く 詳しく知る

自分で動かしたい人は 自分のサーバーを建てる

実際のワールドエディタ。動画プレイヤーやペンを置いて、YAML としても書き出せる。

Why Ubichill

ゆるく、軽く、ひらかれた場所

カーソルだけのゆるい繋がり

顔出しも声出しもなし。お互いの動線だけが伝わる、ちょうどいい存在感。

URL をひらくだけ

インストール不要。低スペックな PC やスマホからでも、ブラウザ 1 つで 1 秒で。

mod でなんでも足せる

ペン・動画・付箋…機能は URL から読み込む mod。ゼロトラストの Worker サンドボックスで安全に動く。

中央を持たない

サーバー同士が連合。どのサーバーの人ともフレンドになり、相手の部屋に入れる。

For builders

ワールドは YAML、
機能は mod。

ワールドは URL で識別される YAML。機能は URL から読み込む mod。どちらも、置いた場所がそのまま配布先になる。

  • World as CodeKubernetes の CRD と同じ形。エディタで編集して YAML に書き出せる。
  • 宣言的な mod SDKUbi.state.sync で全員に同期。外部依存ゼロの @ubichill/sdk。
  • 権限は自動で導出ビルド時の静的解析で必要な権限を出し、初回だけブラウザのカメラ許可のように確認。
    safesensitivedangerous
# worlds/chill-room.yaml
apiVersion: ubichill.com/v1alpha1
kind: World
metadata:
  name: chill-room
  version: "1.0.0"
spec:
  displayName: チルな作業部屋
  capacity: { max: 20, default: 10 }
  dependencies:
    - name: pen
    - name: video-player
  initialEntities:
    - id: pentray
      components:
        - type: pen:tray
// mods/like/src/button.worker.tsx（イメージ）
const likes = Ubi.state.sync(0);

Ubi.ui.render(() => (
  <button onClick={() => likes.set(likes.get() + 1)}>
    いいね {likes.get()}
  </button>
));

// 使っている API から権限を自動導出 → このmodは safe
# 自分のサーバーで動かす
$ helm repo add ubichill https://ubichill.github.io/ubichill
$ helm install ubichill ubichill/ubichill \
    -n ubichill --create-namespace \
    --set global.domain=<your-domain>

# Ingress / CORS / 認証 URL は global.domain から導出
# PostgreSQL はパスワード自動生成で同梱
Federation & self-hosting

どのサーバーの人とも、同じ部屋に

中央のサーバーは置かない。部屋のことは部屋のサーバーが、人のことはその人のホームサーバーが決める。

中央を持たない連合

ActivityPub（AS2）の形でサーバー同士がつながる。フレンド申請も招待も、サーバーをまたいで届く。

chill-room@yokan.dev
パブリックフレンド+フレンドのみ招待のみ

自分のサーバーを建てる

Helm チャートを 1 つ入れるだけ。ドメインを決めれば、あとはだいたい導出される。

$ helm repo add ubichill https://ubichill.github.io/ubichill
$ helm install ubichill ubichill/ubichill \
    -n ubichill --create-namespace \
    --set global.domain=<your-domain>
  • 完全 CSR（Vite）＋ Go の WebSocket インスタンスサーバー
  • PostgreSQL 同梱・パスワード自動生成
  • Ed25519 ＋ RFC 9421 署名でサーバー間を確かめる

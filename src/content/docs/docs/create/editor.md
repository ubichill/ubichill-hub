Ubichill のワールドは、ブラウザのエディタだけで作れます。できあがるのは [World as Code](/docs/create/world-as-code/) と同じ YAML なので、
あとからコードで続きを書くこともできます。

## 新しいワールドを作る

1. 部屋の中でランチパッドを開き、「ワールド」の見出しの「＋」を押します。確認のあと、作成画面に移ります（いまの部屋からは退出します）。
2. 次の項目を入れます。
   - **表示名**（例: ぼくのワールド）
   - **名前（URL）**: 小文字英数と `-` `_`。共有 URL `https://<サーバー>/@<あなたの ID>/<名前>` になります
   - 説明・サムネイル URL（任意）
3. 「下書きとして作成」か「作成して公開」を選びます。まずは下書きで作り、形になってから公開するのが簡単です。

## 画面の見かた

| 場所 | 役割 |
|---|---|
| 左: ヒエラルキー | Entity の木。「ルートに Entity を追加」「子 Entity を追加」、並べ替え（上へ・下へ）、削除、ID の編集（クリックして ID を編集）、タグ |
| 中央: キャンバス | ワールドの見た目。Entity をドラッグして動かす。「スナップ」を ON にするとグリッドに吸い付く |
| 右: インスペクター | 選んだ Entity の Transform（親基準の位置・サイズ）と、各 Component の data |
| 下: アセット | 使える Component の一覧。ここから Entity に Component を付ける |
| 上: ヘッダー | 公開の状態（下書き（未公開）／公開中／公開中・未公開の変更あり）、「下書き保存」（Cmd/Ctrl+S）、「公開する」、「コントロールパネル」 |

## mod を使えるようにする

Component は mod が提供します。まず、ワールドで使う mod を登録します。

1. ヘッダーの「コントロールパネル」を開き、「mod管理」タブを選びます。
2. 使う mod を追加します。本体に同梱の mod（ペン・動画プレイヤーなど）はそのまま選べます。外部の mod は、作者が公開している URL を指定します。
3. バージョンを選びます。「latest（自動追従）」にすると新しい版に追従します。作者の署名がない版は本番では使えないので、別の版を選ぶか一覧から外します。

登録した mod の Component が、下のアセットに並びます。

## Entity を置き、Component を付ける

1. ヒエラルキーで「ルートに Entity を追加」。ID はあとから変えられます（木の中で一意）。
2. アセットから Component を選び、Entity に付けます。1 つの Entity に複数の Component を付けられます（最大 32）。
3. インスペクターで位置・サイズ（Transform）と、Component ごとの data（色・太さ・URL など、mod が宣言したフィールド）を調整します。
4. 入れ子にしたいものは「子 Entity を追加」で、親の下に置きます。子の位置は親からの相対です。

### Component 同士をつなぐ（参照）

動画プレイヤーの「コントロール」と「スクリーン」のように、Component が別の Component を相手にする場合は、インスペクターに参照の枠が出ます。
ヒエラルキーから相手の Entity をドラッグ＆ドロップして指定します。必須の参照が未設定だったり、型が合わなかったりすると、ヒエラルキーとインスペクターに印が出ます。

### 本体に組み込みの Component

mod を登録しなくても使える Component が 3 つあります。

| 型 | 用途 |
|---|---|
| `core:ui` | 看板・説明・リンク。HTML 風の文字列を書く（`script` や `on*` 属性は捨てられる。リンクと画像は https だけ） |
| `core:media` | 動画を描く場所。何を再生するかは、この Entity を参照した mod（動画プレイヤーなど）が決める |
| `core:collider` | 当たり判定の形（矩形か円） |

## YAML を見る

コントロールパネルの「YAML」タブで、いま作っているワールドの YAML がそのまま見えます。ここで直接書き換えることもでき、正しい YAML の間だけ反映されます（構文エラーの間は表示だけ）。
ファイルの読み込みもできます。YAML の書き方は [ワールド定義フォーマット](/docs/create/world-format/) を見てください。

:::tip[コードと行き来する]
エディタで作ったワールドを YAML として取り出し、AI に続きを頼んだり、Git で管理したりできます。[AI と一緒に作る](/docs/create/with-ai/) も見てください。
:::

## ワールドの情報を変える

コントロールパネルの「ワールド情報」タブで、表示名・説明・サムネイル・定員・背景色・ワールドの幅と高さを変えられます。

## 保存と公開

- **下書き保存**（Cmd/Ctrl+S）: 鍵や署名の準備は要りません。公開中のワールドを下書き保存しても、公開中の版はそのままです。
- **公開する**: あなたの作者アカウントで署名して公開します。初めて公開するブラウザでは、自動で鍵が作られ、公開環境として登録されます（確認は出ません）。
  ID をまだ決めていなければ、その場で決めます。

公開できないときは、理由が表示されます。よくあるのは次の 2 つです。

- 署名のない mod（または版）を使っている → 別の版を選ぶか、一覧から外す
- mod を固定（lock）できない → 「再確認してインストール」で取り直す

公開すると、ワールドは一覧とプロフィールに出て、共有 URL `https://<サーバー>/@<ID>/<名前>` からだれでも入れるようになります。
署名のしくみや、CLI・CI から公開する方法は [署名して公開する](/docs/publish/) を見てください。

## 部屋を作って試す

コントロールパネルの上部にある「このワールドで新しいインスタンスを作って参加する」を押すと、いまの内容で部屋を作って入れます。
部屋を作るときに公開範囲（パブリック・フレンド+・フレンドのみ・招待のみ）を選びます。

エディタに戻るには、部屋の中のランチパッド → 現在地 → ワールドの編集画面へ。

## 削除

コントロールパネルの「Danger Zone」を開くと、ワールドを削除できます。取り消せません。公開中のワールドを消すと、共有 URL からも入れなくなります。

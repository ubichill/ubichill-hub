Ubichill は、URL を開くだけで入れる 2D メタバースです。インストールは要りません。
ここでは、公式サーバー [ubichill.com](https://ubichill.com/) を例に、最初の一歩を説明します。
自分のサーバーや、ほかの人のサーバーでも流れは同じです。

## 1. アカウントを作る

1. [ubichill.com](https://ubichill.com/) を開き、「新規登録」を選びます。
2. メールアドレスとパスワード（8 文字以上）、**表示名**と **ID** を入れます。
   - 表示名: 画面に出る名前。日本語も使えます。あとから変えられます。
   - ID: 英小文字・数字・`_` の 3〜30 文字。URL や署名に使われ、**あとから変えられません**。
3. メールに届いた 6 桁の認証コードを入れます（10 分間有効）。届かないときは迷惑メールフォルダを確認し、「認証コードを再送信」を押します。
4. 「ログイン」でログインします。

:::note[作者アカウント]
あなたのアカウントは `ID@ドメイン`（例 `@yokan@ubichill.com`）という形で、ほかのサーバーからも参照されます。
ワールドや mod を公開するときの「作者」もこのアカウントです。詳しくは [署名して公開する](/docs/publish/) を見てください。
:::

## 2. ホームワールドに入る

ログインすると、ロビーのような一覧画面は無く、そのまま**自分のホームワールドの部屋**に入ります。
部屋はログインのたびに新しく作られ、あなたがいなくなれば片付きます。

- 既定のホームは公式のワールドです。設定 → ホームで、好きなワールドをホームにできます。
- ホームの部屋の公開範囲は、既定で**招待のみ**です。ログインするたびに公開一覧へ部屋が出ないようにするためです。
  フレンドに見つけてもらいたいときは、設定 → ホームで公開範囲を「フレンドのみ」などに変えるか、公開の部屋へ移ります。
- 部屋の中では、マウス（スマートフォンでは指）がそのままあなたのアバターになります。ワールドに置かれた mod（ペン・動画プレイヤー・付箋など）をさわって過ごします。

## 3. ランチパッドでできること

部屋の中の右上（スマートフォンでは右下）のボタン、または **Esc** で**ランチパッド**が開きます。
ページを移らずに、ここからすべての操作をします。下のドックで画面を切り替えます。

| ドック | できること |
|---|---|
| ランチパッド | いまの部屋（ワールド・公開範囲・人数）、「ホーム」「招待」、オンラインのフレンド、ワールドの一覧 |
| 通知 | 招待・フレンドリクエスト・その他の通知 |
| 現在地 | いまの部屋の詳細。入り直し・新しいインスタンスを作る・ワールドの編集画面へ・参加者 |
| 音声 | ワールド全体の音量とミュート |
| 設定 | プロフィール・ホーム・ワールド・公開・アカウント・連合・mod の権限 |

- 上に出ている自分のアイコンと名前を押すと、プロフィールが開きます。
- 「フレンド」「ワールド」の見出しから、それぞれソーシャル・ワールドの画面に進みます。ワールドの見出しの「＋」で、新しいワールドを作れます（[エディタでワールドを作る](/docs/create/editor/)）。
- 入力中は Esc が効きません。日本語の変換中も同じです。まず入力欄から抜けてください。

### フレンドを探す

ソーシャルの画面の検索に、ID か表示名を入れます。ほかのサーバーの人は `@ID@ドメイン`（例 `@bob@b.example`）で探せます。
フレンドの申請・承認・解除の規則は [公開範囲・フレンド・招待](/docs/servers/access/) にまとめてあります。

フレンドの現在地は部屋ごとにまとまって出ます。見えない部屋にいるフレンドは「プライベート」とだけ表示され、どこにいるかは出ません。

## 4. ほかの部屋に入る

入り方は 3 つあります。

1. **フレンドのところへ行く**: ソーシャルの画面で、フレンドのいる部屋の「入る」を押します。招待が要る部屋には「入る」の代わりに「リクエスト」が出ます。
2. **ワールドから入る**: ワールドの一覧でワールドを選び、「参加可能なインスタンス」から入るか、「インスタンスを作成」で新しい部屋を作ります。公開範囲はこのときに選びます。
3. **URL から入る**: ワールドの共有 URL（`https://ubichill.com/@ID/ワールド名`）や、部屋の URL をそのまま開きます。ほかのサーバーのワールドの URL でも入れます。ランチパッドの「ワールドの共有 URL を貼って入る」からも開けます。

ほかのサーバーの部屋（住所は `部屋ID@ドメイン`）にも、画面は自分のサーバーのまま入れます。中央のサーバーが無いしくみは [連合のしくみ](/docs/servers/federation/) を見てください。

:::caution[署名のないワールド]
作者の署名が確認できないワールドは一覧に出ません。URL を直接開けば入れますが、入る前に確認の画面が出ます。
署名が保証するのは「その作者が作り、改ざんされていない」ことまでで、安全性の保証ではありません。
:::

## 5. 人を招く

ランチパッドの「招待」から、フレンドを選んでいまの部屋に招待します。ひとことを添えられます（80 文字まで・一度に 20 人まで）。

- 招待された人は、部屋がある間・最長 24 時間、公開範囲にかかわらず入れます。
- 招待のみでない部屋は、入れる人に渡すリンクもコピーできます。招待のみの部屋は URL だけでは入れません。
- 招待の通知からは、そのまま部屋に入れます。

招待を送れる条件（部屋の公開範囲と、送る人が作成者かどうか）は [公開範囲・フレンド・招待](/docs/servers/access/) を見てください。

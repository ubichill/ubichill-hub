Ubichill は、ワールドも mod も自分で作って、自分で持てる 2D メタバース。
ここには使う人・作る人・サーバーを建てる人のための説明をまとめている。

  </Card>
  <Card title="ワールドをつくる" icon="pencil">

## AI に渡す

ワールドの YAML や mod のコードを AI に書いてもらうときは、[`/llms.txt`](/llms.txt)（このドキュメントの目次）か
[`/llms-full.txt`](/llms-full.txt)（全文）を渡す。書き方は [AI と一緒に作る](/docs/create/with-ai/)。

## 本体リポジトリとの関係

リファレンス（API・フォーマット・CLI・権限・アーキテクチャ）は
[ubichill 本体リポジトリ](https://github.com/ubichill/ubichill)のドキュメントをそのまま取り込んでいる。
ページ冒頭に「本体から同期」とあるものは、直すときは本体リポジトリへ。
